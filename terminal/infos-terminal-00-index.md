## Raccourcis clavier

### Linux (Bash)

- `Ctrl + C` : Interrompre commande
- `Ctrl + D` : Fin de fichier (EOF)
- `Ctrl + Z` : Suspendre processus
- `Ctrl + L` : Effacer écran (clear)
- `Ctrl + R` : Rechercher dans historique
- `Tab` : Auto-complétion
- `↑` / `↓` : Naviguer historique

### Windows (CMD)

- `Ctrl + C` : Interrompre commande
- `Tab` : Auto-complétion
- `↑` / `↓` : Naviguer historique
- `F7` : Afficher historique
- `Ctrl + V` : Coller (récent)

### PowerShell

- `Ctrl + C` : Interrompre commande
- `Ctrl + Space` : Auto-complétion
- `Tab` : Auto-complétion
- `↑` / `↓` : Naviguer historique
- `Ctrl + R` : Rechercher historique
